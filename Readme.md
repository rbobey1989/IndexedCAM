# IndexedCAM

Workbench para FreeCAD orientado al mecanizado indexado 3+2.

## Objetivos

- Gestionar orientaciones de mecanizado.
- Crear setups automáticamente.
- Calcular los ejes B y C para cabezales B+C.
- Integrarse con CAM Workbench.
- Generar G-code para máquinas indexadas.

## Estado

En desarrollo. Actualmente incluye el solver geométrico B+C y el registro mínimo
del Workbench para FreeCAD 1.1+.

Consulta [docs/ROADMAP.md](docs/ROADMAP.md) para las fases de desarrollo y
[docs/TESTING.md](docs/TESTING.md) para instalar y probar el addon en FreeCAD.
