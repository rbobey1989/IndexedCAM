 # Definición de máquina

## Tipo

Cabezal B + C.

## Ejes

| Eje | Rango |
| --- | --- |
| B | −90° a +90° |
| C | −360° a +360° |

## Vector de herramienta

La orientación del vector de herramienta se define mediante los ángulos B y C.

## Objetivo

Alinear el eje Z de la herramienta con la normal de la cara seleccionada.
